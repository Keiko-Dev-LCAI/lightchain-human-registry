Lightchain Human Registry

Interactive concept demo, not a live product
This is a concept demo. Everything here is simulated in your browser with pretend data. No real passport is read, no blockchain is used, and nothing leaves this page. Wallet addresses and codes are random fakes.

One passport → one "verified human" badge. Personal data stays on the phone; the registry only stores a private code and a wallet. Try it: connect a wallet, scan a demo passport, then try the same passport from a second wallet, recover a lost wallet, and check the giveaway.
